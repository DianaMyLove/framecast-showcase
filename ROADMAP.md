# FrameCast Development Roadmap

**From Shutter to Screen.**

FrameCast is an offline-first photography platform designed to move images from a camera to a clients device with minimal delay.

## Phase 1 — Capture Foundation
**v0.2.7 | Tested prototype**

- [x] Canon EOS 80D USB connectivity
- [x] Automatic JPEG detection and transfer
- [x] Offline catch-up scanning
- [x] Duplicate-transfer prevention
- [x] USB disconnect and reconnect recovery
- [x] Persistent session logging
- [x] Live terminal status
- [x] Non-destructive camera handling

## Phase 2 — Capture Reliability
**v0.3.x | Planned**

- [ ] Transfer queue and retry management
- [ ] Stronger file identity verification
- [ ] Configurable transfer destinations
- [ ] Transfer progress and performance metrics
- [ ] Automated regression testing
- [ ] Reliable background operation

## Phase 3 — FrameCast Desktop
**v0.4.x | Planned**

- [ ] Professional desktop interface
- [ ] Live image previews
- [ ] Camera connection dashboard
- [ ] Transfer history and session management
- [ ] Transfer settings and preferences

## Phase 4 — Instant Client Delivery
**Future development**

- [ ] Secure automatic cloud uploads
- [ ] Client-specific delivery destinations
- [ ] Private galleries
- [ ] Real-time delivery notifications
- [ ] Resumable uploads and offline queues
- [ ] Client access controls and expiring links

## Phase 5 — FrameCast Mobile
**Future development**

- [ ] Android companion application
- [ ] Camera-to-phone connectivity research
- [ ] Mobile transfer monitoring
- [ ] Client gallery access
- [ ] Delivery notifications

## Phase 6 — Business Integrations
**Future development**

- [ ] Evaluate HoneyBook integration
- [ ] Client and project synchronization
- [ ] Automated gallery delivery workflows
- [ ] Booking-to-delivery automation

Integration capabilities depend on supported third-party APIs.

## Phase 7 — FrameCast Studio
**Long-term vision**

An integrated photography business management platform.

- [ ] Client relationship management (CRM)
- [ ] Booking and scheduling
- [ ] Contracts and electronic signatures
- [ ] Invoicing and payment processing
- [ ] Client communication
- [ ] Photography project management
- [ ] Gallery delivery and download management
- [ ] Business analytics

## Engineering Principles

- Offline-first operation
- Non-destructive camera access
- Secure, permission-based client delivery
- Recoverable transfers
- Modular architecture
- Transparent development milestones

---

**Development status:** Only the v0.2.7 capture foundation has been tested. All other features are proposed and subject to development and validation.
